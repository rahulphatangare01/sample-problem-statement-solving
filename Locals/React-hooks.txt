Hooks 

1. useState - 
              useState is a React hook that allows functional components to manage state.
			  It provides a way to add stateful logic to functional components.
			  
			  Syntax:-
			         const [ count, setCount] = useState(0)
					        this is called as array distruturing
			  Rule of hooks:- 
                             only call Hooks at the top level
							 only call Hooks from react functions
							 
		      use state with object 
			     
				 
			
			useState hook return an array with 2 elements.
			the first element is the current value of state, and second element is state setter function
			when dealing with object and arrays, always make sure to spread your state varible and then call the setter function.
