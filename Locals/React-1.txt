-----------------------  JSX IN REACT -----------------------------------------------------------
   JSX stands for JS XML. It is a syntax extension to JS.
   JSX is a preprocessor step that adds XML syntax to Js.
   JSX produces React 'element'. Its possible Create element without jsx but jsx makes react lot more elegate.
   Jsx is eaiser to read and write. Babel transform these into a actual Js Code. 
   
           JavaScript Expression in JSX
		       We can put any valid JS expression inside the curly braces in JSX. you can pass any JS expression as children,
			   by enclosing it within {}.
			   
			   Syntax:- {expression}
			   EX:-  
			      const el = <h1>{10+20} </h1>
